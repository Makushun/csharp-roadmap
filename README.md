# C# Roadmap 🚀

Интерактивная визуальная карта для изучения C# с отслеживанием прогресса.

## Особенности

- 📊 Визуальная карта с 39+ темами по C#
- ✅ Отслеживание пройденных тем
- 💾 Автосохранение прогресса в localStorage
- 🎨 Современный тёмный дизайн
- 🔍 Масштабирование и перетаскивание
- 📱 Адаптивный дизайн

## Категории

- 📘 Основы C#
- 🏗️ ООП
- ⚙️ Продвинутый OOP
- ⚡ Асинхронное программирование
- 🌐 .NET Экосистема
- 🗄️ Работа с данными
- 🧪 Тестирование
- 🚀 Web Development
- 📐 Паттерны проектирования
